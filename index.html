Bellbird

Aplicación de escritorio para Windows que lee en voz alta el chat de los directos de YouTube y TikTok. Está pensada para personas ciegas o con baja visión que transmiten: todo se maneja con el teclado y se prueba con el lector de pantalla NVDA.

Se llama así por el pájaro campana, el ave nacional de Paraguay. Hasta la versión 2.5 se llamaba YTChat TTS.

Qué hace

  • Lee el chat de un directo de YouTube o de TikTok, con un sonido distinto para cada tipo de mensaje.
  • Lee y publica comentarios en vídeos de YouTube, y modera el chat con la cuenta de Google de quien la usa.
  • Reproduce el vídeo del directo dentro de la aplicación.
  • Empieza y termina el directo con OBS Studio.
